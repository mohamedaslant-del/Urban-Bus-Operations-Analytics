# Urban Bus Operations Analytics

## Project Overview
This project analyzes urban bus operations to understand trip performance, departure delays, passenger occupancy, trip status, and revenue using Python, SQL, and Power BI.

## Dataset
- 5,000 bus trip records
- Route and bus information
- Scheduled and actual departure times
- Passenger count and bus capacity
- Delay minutes and trip status
- Ticket revenue and fuel cost

## Tools Used
- Python — Data cleaning, validation, and analysis
- MySQL — SQL queries and business analysis
- Power BI — Interactive dashboard and visualizations

## Key Performance Indicators (KPIs)
- Total Trips
- Total Revenue
- Average Occupancy
- On-Time Performance
- Delayed Trips
- Cancelled Trips

## Key Insights
- 2,982 trips were on time (59.64%).
- 1,861 trips were delayed (37.22%).
- 157 trips were cancelled (3.14%).
- Average occupancy was 60.61%.
- Total ticket revenue was ₹51,81,339.
- 6 PM had the highest number of trips and delayed trips.
